# DemonGacha in GD

Mod de Geode para GD 2.2091 (Geode 6.0.0-alpha.2). Añade un botón **DG** en el menú principal que abre demongacha.com en el navegador.

## Compilar
GitHub Actions lo compila solo en cada push. El `.geode` se publica en **Releases** (también está en Actions → Artifacts).

## Instalar
Copia el `.geode` en `Geometry Dash/geode/mods/` y abre el juego.
